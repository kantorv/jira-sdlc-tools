# Account, repository, and authentication

You need a GitHub account and a repository. The repository is the main source
repository from which the skills create issue branches and worktrees.

Create a **granular GitHub PAT** with:

- `Contents` — read/write
- `Pull requests` — read/write

GitHub may also show `Metadata` / `Meta` as a read permission; it is added
automatically.

See [Creating a GitHub PAT](../../../process/SECURITY.md#github) and
[GH-PAT-SESSION-LOGIN.md](../../../github/GH-PAT-SESSION-LOGIN.md).
