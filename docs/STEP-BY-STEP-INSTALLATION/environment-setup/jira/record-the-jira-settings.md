# Record the Jira settings

Put the project key and four status names in `.jst/jira-sdlc-tools.env`:

```text
PROJECT_KEY=PROJ
STATUS_TODO=To Do
STATUS_IN_PROGRESS=In Progress
STATUS_IN_REVIEW=In Review
STATUS_DONE=Done
```

Substitute the project key and status names from your own board.
