# Account, project, and board

You need a Jira account and a project with a board. The plugin was tested on a
simple Kanban board — the default Kanban template, with its default columns,
is the known-good setup. Scrum boards and custom workflows should work provided
the required four statuses exist, but they aren't what was exercised.
